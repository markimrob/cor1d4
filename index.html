A versão abaixo é um **arquivo HTML único**, adaptado para celular: tem botões de toque para virar, acelerar e frear, além de controles de teclado. Salve como `index.html`. O Three.js é carregado por CDN, então é necessária conexão com a internet. ```html Corrida 3D
🏁 0 m
⚡ 0 km/h

Corrida 3D

Desvie dos carros e tente chegar o mais longe possível.
Celular: use os botões na tela.
Computador: ← → ou A/D; acelere com ↑/W e freie com ↓/S.

```
